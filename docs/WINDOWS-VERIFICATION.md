## 发现并修复

1. 此 Windows 驱动启动 GATT 广播时短暂报告 `Aborted / Success`，随后进入 `Started`。客户端原先在第一个事件立刻停止，取消了正常启动。现在等待 750 ms 并核对当前状态，仅在仍然中止时停止。真实适配器与安装后的客户端均显示广播就绪；持续失败仍会显示明确错误。
2. Hvigor 的 `PackageHap` 按名称执行 `java`，仅设置 `JAVA_HOME` 会报 `spawn java ENOENT`。构建包装器将 DevEco 自带 `jbr/bin` 加入子进程 PATH，保留原 PATH 大小写及 SDK 覆盖配置，不修改系统环境变量。随后签名构建通过。
