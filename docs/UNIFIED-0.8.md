# 0.8：统一电脑体验与多电脑配对

Windows 工作台与鸿蒙手机采用同一套「互传 / 快捷指令 / 连接 / 设置」语言。手机使用「我的电脑」管理 Windows 和 Mac，平台仅作为名称旁的标识，不再决定一套独立流程。Mac 客户端继续保留，配对引导同步更新。

## 交互与数据

- Windows 使用蓝灰色工作台、SVG 图标、连接状态卡、按日期分组的历史和明确的收取状态。蓝牙、队列重试、文件夹发送进入页面；加载失败时保留原生工具栏。
- 手机最多保留 8 台电脑。扫码同一公钥更新原条目，扫码另一台添加条目。切换后输入草稿保留，并明确提示发送目标；历史、待发文件、待确认操作、证书及蓝牙设置各自隔离。
- 升级时将原单电脑配对原地迁移，不移动已接收文件。此前被旧版覆盖的另一台电脑，需要重新扫码添加一次；升级不能恢复已经丢失的凭据。
- 分享页在开始前可选择目标。开始后保存目标身份与名称，每次续传、每条内容提交前都检查当前身份，避免暂停期间切换电脑后将剩余内容发错地方。
- 移除只从手机可选列表中移除，不删除本地保留文件、不撤销电脑上已经执行的操作，也不代替电脑端撤销手机授权。
- 新增可选 `platform` 元数据；历史协议中的 `role/source: mac` 保持兼容。
